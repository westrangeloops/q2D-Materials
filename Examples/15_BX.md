# 15. B-X-B Bond Angles and Bond Lengths

B-X-B bond angles describe the angle between adjacent octahedra sharing an X-site atom. These angles are critical for understanding:
- Octahedral tilting patterns
- Phase transitions
- Electronic band structure
- Transport properties

The analyzer provides both programmatic access to angle/distance data and convenient plotting methods.

## B-X-B Bond Angles

### Basic Usage

Get B-X-B bond angle data:

```python
from q2D_Materials.analyzer import q2D_analyzer
from q2D_Materials.core.creator import q2D_creator

# Create and analyze structure with Glazer tilting for distortion
# TODO: Fix jahn_teller_dist implementation - currently only scales c-axis, 
#       doesn't apply distortion to individual B-X bonds. Need to implement 
#       proper Jahn-Teller distortion that elongates/compresses octahedra.
# Using Glazer tilting instead to create bond length variation
q2d = q2D_creator()
structure = q2d.create_structure(
    structure_type="monolayer",
    A_ions="MA", B_ions="Pb", X_ions="I",
    xy_expansion=(2, 2), template="cubic",
    thickness=2, vacuum=15.0,
    glazer_pattern="a+b-b-",  # Add octahedral tilting to create bond length variation
)

analyzer = q2D_analyzer(structure)
analyzer.analyze()

# Get B-X-B angles
bxb_data = analyzer.get_bxb_angles()

# Access results
angles = bxb_data['bxb_angles']  # Array of angles in degrees
mean = bxb_data['bxb_mean']      # Mean angle
std = bxb_data['bxb_std']        # Standard deviation

print(f"Mean B-X-B angle: {mean:.2f}°")
print(f"Standard deviation: {std:.2f}°")
print(f"Number of angles: {len(angles)}")
```

### Parameters

Control angle calculation:

```python
bxb_data = analyzer.get_bxb_angles(
    bxb_scale=1.4,          # Scale factor for bond cutoff
    supercell=(1, 1, 1),    # Supercell expansion
    include_bp=False        # Include B-X-Bp angles (spacer B-sites)
)
```

### Including B-X-Bp Angles

For layered structures with spacer B-sites:

```python
bxb_data = analyzer.get_bxb_angles(include_bp=True)

# B-X-B angles (inorganic framework)
bxb_angles = bxb_data['bxb_angles']
bxb_mean = bxb_data['bxb_mean']

# B-X-Bp angles (framework to spacer)
bxbp_angles = bxb_data['bxbp_angles']
bxbp_mean = bxb_data['bxbp_mean']

print(f"B-X-B angles: {bxb_mean:.2f}°")
print(f"B-X-Bp angles: {bxbp_mean:.2f}°")
```

## Plotting B-X-B Angles

The analyzer provides data extraction for angle distributions. You can then create custom plots:

```python
import matplotlib.pyplot as plt
import numpy as np

# Get B-X-B angle data
bxb_data = analyzer.get_bxb_angles()
angles = bxb_data['bxb_angles']
mean_angle = bxb_data['bxb_mean']
std_angle = bxb_data['bxb_std']

# Create custom plot
fig, ax = plt.subplots(figsize=(10, 6))
ax.hist(angles, bins=60, alpha=0.7, color='steelblue', edgecolor='black')
ax.axvline(mean_angle, color='red', linestyle='--', linewidth=2,
           label=f'Mean: {mean_angle:.2f}°')
ax.set_xlabel('B-X-B Angle (degrees)', fontsize=12)
ax.set_ylabel('Frequency', fontsize=12)
ax.set_title(f'B-X-B Bond Angles (σ = {std_angle:.2f}°)', fontsize=14)
ax.legend()
ax.grid(alpha=0.3)
plt.tight_layout()
plt.savefig("bxb_angles.png", dpi=300, bbox_inches='tight')
plt.close()
```

**Return type:** `get_bxb_angles()` returns a dict with:
- `'bxb_angles'`: numpy array of angles in degrees
- `'bxb_mean'`: mean angle (float)
- `'bxb_std'`: standard deviation (float)

## X-B-X Bond Angles

X-B-X angles are the angles within octahedra (should be 90° or 180° for ideal octahedra):

```python
import matplotlib.pyplot as plt
from q2D_Materials.analyzer.characterization.distortions import _compute_octahedral_distortions

# Get X-B-X angle data
distortions = _compute_octahedral_distortions(analyzer)
xbx_angles = distortions['bond_angles']
mean_angle = distortions['mean_angle']

# Create custom plot with ideal angle markers
fig, ax = plt.subplots(figsize=(10, 6))
ax.hist(xbx_angles, bins=80, alpha=0.7, color='coral', edgecolor='black')
ax.axvline(mean_angle, color='red', linestyle='--', linewidth=2,
           label=f'Mean: {mean_angle:.2f}°')
ax.axvline(90, color='green', linestyle=':', linewidth=1.5,
           label='Ideal 90°', alpha=0.7)
ax.axvline(180, color='blue', linestyle=':', linewidth=1.5,
           label='Ideal 180°', alpha=0.7)
ax.set_xlabel('X-B-X Angle (degrees)', fontsize=12)
ax.set_ylabel('Frequency', fontsize=12)
ax.set_title('X-B-X Bond Angles', fontsize=14)
ax.legend()
ax.grid(alpha=0.3)
plt.tight_layout()
plt.savefig("xbx_angles.png", dpi=300, bbox_inches='tight')
plt.close()
```

**Return type:** `_compute_octahedral_distortions()` returns a dict with:
- `'bond_angles'`: numpy array of X-B-X angles
- `'mean_angle'`: mean angle (float)
- `'bond_lengths'`: numpy array of B-X bond lengths (may be empty if no octahedra found)
- `'mean_bond_length'`: mean bond length (float, may be 0.0 if no data)

**Note:** If bond lengths are all zeros or empty, ensure:
1. The structure has been analyzed: `analyzer.analyze()`
2. The structure contains octahedra: `len(analyzer.get_octahedra()) > 0`
3. Octahedra have valid B-X bonds (check `analyzer.get_octahedra()` for valid central atoms)

## Bond Length Distributions

### B-X Bond Lengths

Get B-X bond length data and create custom plots:

```python
import matplotlib.pyplot as plt
import numpy as np
from q2D_Materials.analyzer.characterization.distortions import _compute_octahedral_distortions

# Get B-X bond length data
distortions = _compute_octahedral_distortions(analyzer)
bond_lengths = distortions['bond_lengths']
mean_length = distortions['mean_bond_length']

# Check if we have valid data
if len(bond_lengths) > 0 and mean_length > 0:
    # Create custom plot
    fig, ax = plt.subplots(figsize=(10, 6))
    ax.hist(bond_lengths, bins=40, alpha=0.7, color='mediumseagreen', edgecolor='black')
    ax.axvline(mean_length, color='red', linestyle='--', linewidth=2,
               label=f'Mean: {mean_length:.3f} Å')
    ax.set_xlabel('B-X Bond Length (Å)', fontsize=12)
    ax.set_ylabel('Frequency', fontsize=12)
    std_dist = np.std(bond_lengths)
    ax.set_title(f'B-X Bond Lengths (σ = {std_dist:.3f} Å)', fontsize=14)
    ax.legend()
    ax.grid(alpha=0.3)
    plt.tight_layout()
    plt.savefig("bx_distances.png", dpi=300, bbox_inches='tight')
    plt.close()
else:
    print("Warning: No bond length data available")
```

**Return type:** `_compute_octahedral_distortions()` returns a dict with:
- `'bond_lengths'`: numpy array of B-X bond lengths (may be empty if no octahedra found)
- `'mean_bond_length'`: mean bond length (float, may be 0.0 if no data)
- `'bond_angles'`: numpy array of X-B-X angles
- `'mean_angle'`: mean X-B-X angle (float)

**Note:** If bond lengths are all zeros or empty, ensure:
1. The structure has been analyzed: `analyzer.analyze()`
2. The structure contains octahedra: `len(analyzer.get_octahedra()) > 0`
3. Octahedra have valid B-X bonds (check `analyzer.get_octahedra()` for valid central atoms)

## Octahedral Distortion Parameters

Compute quantitative distortion metrics:

```python
# Delta: Bond length distortion
delta = analyzer.compute_delta()
print(f"Δ (bond length distortion): {delta:.4f}")

# Sigma: Bond length variance
sigma = analyzer.compute_sigma()
print(f"σ² (bond length variance): {sigma:.6f}")

# Lambda: Bond angle variance
lambda_param = analyzer.compute_lambda()
print(f"λ² (bond angle variance): {lambda_param:.4f}")
```

**Parameter meanings:**
- **Δ (delta)**: Mean absolute deviation of B-X bond lengths (0 = ideal)
- **σ² (sigma)**: Normalized variance of B-X bond lengths
- **λ² (lambda)**: Variance of X-B-X angle deviations from ideal (90°/180°)

## Analyzing Angle Distributions

Extract detailed statistics from angle data:

```python
import numpy as np

# Get B-X-B angles
bxb_data = analyzer.get_bxb_angles()
angles = bxb_data['bxb_angles']

# Statistics
mean_angle = np.mean(angles)
median_angle = np.median(angles)
std_angle = np.std(angles)
min_angle = np.min(angles)
max_angle = np.max(angles)

print(f"Mean:   {mean_angle:.2f}°")
print(f"Median: {median_angle:.2f}°")
print(f"Std:    {std_angle:.2f}°")
print(f"Range:  {min_angle:.2f}° - {max_angle:.2f}°")

# Count angles in ranges
near_linear = np.sum((angles >= 175) & (angles <= 180))
bent = np.sum((angles >= 150) & (angles < 175))
highly_bent = np.sum(angles < 150)

print(f"\nAngle distribution:")
print(f"  Near-linear (175-180°): {near_linear}")
print(f"  Bent (150-175°): {bent}")
print(f"  Highly bent (<150°): {highly_bent}")
```

## Correlation with Glazer Patterns

B-X-B angles correlate with Glazer tilt patterns:

```python
# Get angles
bxb_data = analyzer.get_bxb_angles()
mean_bxb = bxb_data['bxb_mean']

# Get Glazer pattern
glazer = analyzer.get_glazer_pattern()
pattern = glazer['notation']

print(f"Glazer pattern: {pattern}")
print(f"Mean B-X-B angle: {mean_bxb:.2f}°")

# Interpretation
if mean_bxb > 170:
    print("→ Small tilting, near cubic")
elif mean_bxb > 160:
    print("→ Moderate tilting")
else:
    print("→ Strong tilting")
```

## Complete Example

```python
from q2D_Materials.analyzer import q2D_analyzer
from q2D_Materials.core.creator import q2D_creator
import numpy as np

# Create structure with Glazer tilting to show bond length variations
# TODO: Fix jahn_teller_dist - currently only affects c-axis, not individual bonds
q2d = q2D_creator()
structure = q2d.create_structure(
    structure_type="dj",
    A_ions="EDBE", B_ions="Pb", X_ions="I",
    xy_expansion=(2, 2), template="cubic",
    thickness=2, vacuum=15.0,
    glazer_pattern="a+b-b-",  # Add octahedral tilting for bond length variation
)

analyzer = q2D_analyzer(structure)
analyzer.analyze()

print(f"Structure type: {analyzer.structure_type}")
print(f"Octahedra count: {len(analyzer.get_octahedra())}")
print()

# 1. Distortion parameters
print("Octahedral Distortions:")
print(f"  Δ = {analyzer.compute_delta():.4f}")
print(f"  σ² = {analyzer.compute_sigma():.6f}")
print(f"  λ² = {analyzer.compute_lambda():.4f}")
print()

# 2. B-X-B angle analysis
bxb_data = analyzer.get_bxb_angles(include_bp=True)
print("B-X-B Angles:")
print(f"  Mean: {bxb_data['bxb_mean']:.2f}°")
print(f"  Std:  {bxb_data['bxb_std']:.2f}°")
print(f"  Count: {len(bxb_data['bxb_angles'])}")

if bxb_data['bxbp_angles'] is not None:
    print(f"\nB-X-Bp Angles (to spacer):")
    print(f"  Mean: {bxb_data['bxbp_mean']:.2f}°")
    print(f"  Count: {len(bxb_data['bxbp_angles'])}")
print()

# 3. Glazer pattern
try:
    glazer = analyzer.get_glazer_pattern()
    print(f"Glazer pattern: {glazer['notation']}")
    print(f"Tilt angles: {glazer['tilt_angles']}")
except:
    print("Glazer pattern: Not detected")
print()

# 4. Create visualizations
print("Creating plots...")
import matplotlib.pyplot as plt
import numpy as np
from q2D_Materials.analyzer.characterization.distortions import _compute_octahedral_distortions

# B-X-B angles
bxb_data = analyzer.get_bxb_angles()
angles = bxb_data['bxb_angles']
if angles is not None and len(angles) > 0:
    fig, ax = plt.subplots(figsize=(10, 6))
    ax.hist(angles, bins=50, alpha=0.7, color='steelblue', edgecolor='black')
    ax.axvline(bxb_data['bxb_mean'], color='red', linestyle='--', linewidth=2)
    ax.set_xlabel('B-X-B Angle (degrees)')
    ax.set_ylabel('Frequency')
    ax.set_title(f'B-X-B Bond Angles (σ = {bxb_data['bxb_std']:.2f}°)')
    ax.grid(alpha=0.3)
    plt.tight_layout()
    plt.savefig("bxb_angles.png", dpi=300, bbox_inches='tight')
    plt.close()

# X-B-X angles
distortions = _compute_octahedral_distortions(analyzer)
xbx_angles = distortions['bond_angles']
if len(xbx_angles) > 0:
    fig, ax = plt.subplots(figsize=(10, 6))
    ax.hist(xbx_angles, bins=50, alpha=0.7, color='coral', edgecolor='black')
    ax.axvline(distortions['mean_angle'], color='red', linestyle='--', linewidth=2)
    ax.set_xlabel('X-B-X Angle (degrees)')
    ax.set_ylabel('Frequency')
    ax.set_title('X-B-X Bond Angles')
    ax.grid(alpha=0.3)
    plt.tight_layout()
    plt.savefig("xbx_angles.png", dpi=300, bbox_inches='tight')
    plt.close()

# B-X bond lengths
bond_lengths = distortions['bond_lengths']
mean_length = distortions['mean_bond_length']

# Check if we have valid bond length data
if len(bond_lengths) > 0 and mean_length > 0:
    # Adjust bins if needed
    data_range = np.max(bond_lengths) - np.min(bond_lengths)
    unique_values = len(np.unique(bond_lengths))
    if data_range < 1e-6 or unique_values < 50:
        adjusted_bins = min(50, max(unique_values, 1))
    else:
        adjusted_bins = 50
    
    fig, ax = plt.subplots(figsize=(10, 6))
    ax.hist(bond_lengths, bins=adjusted_bins, alpha=0.7, color='mediumseagreen', edgecolor='black')
    ax.axvline(mean_length, color='red', linestyle='--', linewidth=2,
               label=f'Mean: {mean_length:.3f} Å')
    ax.set_xlabel('B-X Bond Length (Å)')
    ax.set_ylabel('Frequency')
    std_dist = np.std(bond_lengths)
    ax.set_title(f'B-X Bond Lengths (σ = {std_dist:.3f} Å)')
    ax.legend()
    ax.grid(alpha=0.3)
    plt.tight_layout()
    plt.savefig("bx_distances.png", dpi=300, bbox_inches='tight')
    plt.close()
else:
    print(f"Warning: No valid bond length data (mean={mean_length}, count={len(bond_lengths)})")
    print("This may indicate the structure has no octahedra or analysis failed.")

# RDF - Auto-detect element pairs
from q2D_Materials.analyzer.utils.geometry_helpers import get_all_x_atoms_from_octahedron
octahedra = analyzer.get_octahedra()
atom_symbols = analyzer.cell.get_chemical_symbols()

b_elements = set()
x_elements = set()

for oct in octahedra:
    if oct['central_atom_symbol']:
        b_elements.add(oct['central_atom_symbol'])
    for idx in get_all_x_atoms_from_octahedron(oct):
        x_elements.add(atom_symbols[idx])

# Create B-X pairs
element_pairs = [[b, x] for b in sorted(b_elements) for x in sorted(x_elements)]

if not element_pairs:
    # Fallback: use all unique elements (limit to 3 most common)
    unique_elements = sorted(set(atom_symbols))[:3]
    element_pairs = [[e1, e2] for i, e1 in enumerate(unique_elements)
                    for e2 in unique_elements[i:]]

rdf_data = analyzer.get_partial_rdf(element_pairs=element_pairs, max_dist=12.0)
fig, ax = plt.subplots(figsize=(10, 6))
colors = plt.cm.tab10(np.linspace(0, 1, len([k for k in rdf_data.keys() if k.endswith('_rdf')])))
idx = 0
for key in sorted(rdf_data.keys()):
    if key.endswith('_rdf'):
        pair_key = key.replace('_rdf', '')
        x_key = f"{pair_key}_x"
        if x_key in rdf_data:
            ax.plot(rdf_data[x_key], rdf_data[key], 
                   label=f"{pair_key[0]}-{pair_key[1]}" if len(pair_key) == 2 else pair_key,
                   color=colors[idx], linewidth=2)
            idx += 1
ax.set_xlabel('Distance (Å)')
ax.set_ylabel('g(r)')
ax.set_title('Radial Distribution Function')
ax.legend(loc='best')
ax.grid(alpha=0.3)
ax.set_xlim(0, 12.0)
plt.tight_layout()
plt.savefig("rdf.png", dpi=300, bbox_inches='tight')
plt.close()

print("✓ Plots saved")
```

## API Summary

### Data Access Methods

| Method | Purpose | Returns |
|--------|---------|---------|
| `get_bxb_angles()` | Get B-X-B angle data | dict with angles, mean, std |
| `compute_delta()` | Bond length distortion | float (Δ) |
| `compute_sigma()` | Bond length variance | float (σ²) |
| `compute_lambda()` | Bond angle variance | float (λ²) |

### Data Extraction Methods

| Method | Purpose | Returns |
|--------|---------|---------|
| `get_bxb_angles()` | Get B-X-B angle data | dict with `bxb_angles` (array), `bxb_mean`, `bxb_std` |
| `get_octahedral_distortions()` | Get X-B-X angles and bond lengths | dict with `bond_angles`, `bond_lengths`, `mean_angle`, `mean_bond_length` |
| `get_partial_rdf()` | Get RDF data | dict with `{pair}_x` and `{pair}_rdf` arrays |

### When to Use Each Method

- **`get_bxb_angles()`**: When you need B-X-B angle data for custom analysis or plotting
- **`get_octahedral_distortions()`**: When you need X-B-X angles or B-X bond lengths for custom analysis
- **`get_partial_rdf()`**: When you need RDF data for custom plotting or analysis
- **`compute_delta/sigma/lambda()`**: For quantitative distortion metrics in publications

**Note:** The analyzer provides data extraction methods. You can create custom plots using matplotlib with the returned data arrays.

## Relationship to Glazer Notation

B-X-B angles relate directly to Glazer tilt patterns:

```python
# Get both
bxb_data = analyzer.get_bxb_angles()
glazer = analyzer.get_glazer_pattern()

print(f"Mean B-X-B: {bxb_data['bxb_mean']:.2f}°")
print(f"Glazer: {glazer['notation']}")
print(f"Tilt magnitudes: {glazer['tilt_angles']}")

# Deviation from 180° relates to tilt magnitude
deviation = 180.0 - bxb_data['bxb_mean']
print(f"Average tilt: ~{deviation/2:.1f}°")
```
