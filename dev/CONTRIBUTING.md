# Contributing to q2D-Materials

## Quick start (recommended)

```bash
devenv shell
pytest tests/
```

## Make a change

1. Fork the repository and create a branch.
2. Make your code or documentation changes.
3. Run `pytest tests/` (inside `devenv shell`).
4. Commit, push, and open a pull request against `main` or `develop`.
